**기능 소개 섹션:**

### 3. 카테고리 자동 분류 + 노션 DB
![database](./assets/05_notion_database.jpg)

## 📤 영상 호스팅 옵션

원본 영상은 79MB라 GitHub에 그대로 못 올립니다 (100MB 제한이지만 Git LFS 필요). 다음 옵션 추천:

### 옵션 A: YouTube 비공개(Unlisted)
- ✅ **강력 추천**
- 무료, 무제한, 영구
- URL 가진 사람만 시청 가능
- 자동 트랜스코딩(저화질 자동 제공)
- **단점**: 광고 노출 가능 (모바일에서)

### 옵션 B: Vimeo
- 비공개 공유 강력
- 깔끔 (광고 없음)
- 무료 플랜은 주간 업로드 한도

### 옵션 C: GitHub Releases
- Repo의 Release 페이지에 첨부
- 2GB까지 가능
- README에서 직접 임베드 안 됨 (링크만)

### 옵션 D: 자체 호스팅 (S3 / Cloudflare R2)
- 가장 컨트롤 강하지만 비용·관리 부담

**추천 흐름:**
1. `demo_full_720p.mp4` (2.4MB) → **YouTube unlisted** 업로드

## 🎁 시연 영상이 만드는 임팩트

면접관 입장에서 시연 영상이 있는 포트폴리오와 없는 포트폴리오의 차이:

| 영상 없음 | 영상 있음 |
|---|---|
| "글로만 봐선 진짜 동작하는지 모르겠는데?" | "오, 진짜 카톡에서 노션까지 흐르네" |
| 기술 스택 나열로만 보임 | 시스템 완성도가 가시적으로 증명됨 |
| 면접에서 *"시연 가능한가요?"* 추가 질문 | 이미 답변 끝남 |
| 정량 수치만 보고 의심 | 수치 + 시각 증거 모두 |

→ 시연 영상은 포트폴리오 **신뢰도를 1.5~2배 올리는** 가장 효과적인 자산입니다.
