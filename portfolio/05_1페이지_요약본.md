| 지표 | 값 |
|---|---|
| 카카오톡 5초 응답률 | **100%** |
| 영상 1편 자동 요약 시간 | 약 30~120초 (추정) |

| 할루시네이션 방어 | **4중** (임계값·프롬프트·출처·빈결과 분기) |
| 트러블슈팅 해결 | 침묵 실패 1건 (Celery on_error) |

## 🧠 핵심 설계 결정 5가지

1. **AI 라우터를 LLM 구조화 출력 기반으로 설계** — 룰 기반(키워드 매칭) 대신 자연어 이해로 부정문·인용까지 분류
2. **요약본을 임베딩** (원본 자막 대신) — 노이즈 제거로 검색 변별력 확보
3. **거리 임계값 필터링** (RAG 0.7 / 유사 영상 0.8) — 할루시네이션 사전 방어
4. **채널 분리 정책** (영상 요약→노션 / 검색 결과→메일 / 카톡엔 ACK) — 챗봇 발송 비용 0 + 영구 보관
5. **FIND_SIMILAR을 UPLOAD 파이프라인 재사용 + 플래그 통합** — 코드 중복 제거

## 🔧 트러블슈팅 한 줄

3단계 Celery chain의 `.on_error()` 핸들러가 호출되지 않고 사용자에겐 아무 안내도 가지 않는 **침묵 실패** 발생 → Celery 워커 로그·공식 문서 정독으로 `.on_error()` 콜백이 `(request, exc, traceback)` 3개 인자를 **자동으로 주입**한다는 사실 발견 → 시그니처 확장으로 해결 → 파이프라인 실패 시 DB FAILED 마킹 + 사용자 안내 메일 정상 동작.
